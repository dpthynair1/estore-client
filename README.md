# E-Store Client

This repository contains the **frontend client** for my personal e-commerce project built using React (bootstrapped with Create React App). It was created as a learning project to explore UI structure, component design, and integration with an API backend.

## 🧠 What this demonstrates
- React component structure  
- Application layout and state management  
- Communication with server API (handled via REST endpoints)  
- Basic routing and UI interactions
